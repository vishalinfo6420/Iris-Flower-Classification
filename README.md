# 🌸 Iris Flower Classification using Machine Learning

## 📌 Project Overview

This project is an end-to-end Machine Learning application that classifies Iris flowers into three species—**Iris Setosa**, **Iris Versicolor**, and **Iris Virginica**—based on four flower measurements using the **Random Forest Classifier**.

The trained model is deployed with **Streamlit**, allowing users to enter flower measurements and receive instant predictions through a simple web interface.

---

## 🚀 Features

* Load and explore the Iris dataset
* Data preprocessing and feature selection
* Train-Test Split (80:20)
* Random Forest Classifier for prediction
* Model evaluation using:

  * Accuracy Score
  * Confusion Matrix
  * Classification Report
* Save the trained model using Pickle
* Interactive Streamlit web application
* Real-time flower species prediction
